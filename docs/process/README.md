- **Review-gate check for any round touching `src/screening_workbench/app.py`:** before pushing, confirm `docs/ui-convergence-log.md` is in the commit's changed-files list (`git diff --name-only` against the prior pushed commit). A detailed commit message describing the UI change is not a substitute for a log entry — score the affected checklist item(s), recompute the running total with `python3` (never by hand), attach the required live PNG, and update the Convergence status section if a tab's closed state changes. A commit that touches `app.py` without a matching `ui-convergence-log.md` entry fails the review gate and must not be pushed as-is.
